# ml/experiments

One file per experiment, named `NNNN-short-slug.md`, numbered in order. Start from
`TEMPLATE.md`.

**Sections 1 to 7 are committed before the work. Sections 8 to 12 after.** Git history then
shows the hypothesis preceded the result. The reasoning is in `docs/repository.md` section 6;
the short version is that records written entirely afterwards are how failures quietly stop
getting documented.

Failures are valid results. An experiment that failed and was written up is worth more than one
that succeeded and was not.

Exploratory work that never becomes an experiment belongs in `notebooks/` and needs no record.
